# 面向离职风险的电子数据取证与审计系统

本项目面向“电子数据取证系统研发”实训题目，选择企业员工离职数据泄露风险作为具体应用场景，设计并实现一个本地运行的电子数据取证辅助系统。

系统面向授权取证人员，支持对指定员工工作目录、聊天记录样本、USB 使用记录和浏览器访问记录进行综合分析，生成风险评分、事件时间线和 PDF 取证分析报告。

## 项目定位

本系统不是企业级远程全量自动取证平台，而是本地运行的电子数据取证辅助工具。

调整原因：

- 电子取证数据主要来自本地环境，包括文件目录、浏览器历史、聊天数据库、注册表和 USB 记录。
- 普通 Web 浏览器无法直接读取用户本地目录、注册表和应用数据库。
- 如果 Web 端要完成真实本地取证，需要额外安装本地 Agent，这与直接开发 PyQT 本地客户端的技术路线接近。
- 因此当前阶段将 PyQT 作为主要取证入口，Web 端保留为辅助展示和接口调试模块。

## 核心功能

- 文件系统取证采集：扫描指定工作目录，提取文件路径、大小、类型、时间和哈希。
- 文档内容解析：支持 txt、docx、xlsx、pdf、csv、json、html、md 等文件类型。
- 敏感内容识别：基于关键词匹配识别客户名单、商业计划、源代码、机密数据等内容。
- 即时通信样本解析：支持读取 `test_data/mock_chat.sqlite` 标准化聊天记录样本。
- USB 使用记录分析：读取本机注册表提取 USB 存储设备插拔记录。
- 浏览器记录分析：尝试读取本机 Chrome、Edge、Firefox 历史记录并识别网盘、邮箱访问。
- 时间线重建：将文件、内容、聊天、USB、浏览器事件按时间排序。
- 风险评分：基于敏感文件、聊天泄露意图、USB、压缩包、网盘访问等多源证据综合评分。
- 报告生成：生成离职场景电子数据取证分析 PDF 报告。

## 运行方式

安装依赖：

```bash
pip install -r requirements.txt
```

启动 PyQT 本地客户端：

```bash
python main.py
```

推荐演示参数：

```text
员工姓名：张三
工作目录路径：test_data
聊天记录样本：test_data/mock_chat.sqlite
```

启动 Web 辅助展示端：

```bash
python api.py
```

访问：

```text
http://127.0.0.1:5000
```

说明：Web 端当前用于参数填写、任务进度展示、结果查看和报告下载。它不承担核心本地取证入口，因为普通浏览器无法直接读取本地注册表、聊天数据库和任意本地目录。

## 测试数据

`test_data/mock_chat.sqlite`：

- 模拟微信/QQ 聊天记录。
- 用于验证聊天记录解析、泄露关键词识别和时间线聚合。

`test_data/客户资料打包.zip`：

- 模拟离职前打包敏感资料的压缩包证据。
