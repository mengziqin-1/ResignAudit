## 1. `src/modules/file_scanner.py` — 修复 Web 端日期类型崩溃

**问题**：Web 端传入 `datetime`，GUI 端传入 `date`，直接比较导致 `TypeError`。

### 修改前
```python
def scan_directory(self, directory, audit_start_date, audit_end_date, progress_callback=None):
    self.scan_results = []
    self.total_files = 0
    self.scan_start_time = datetime.now()
    
    if not os.path.exists(directory):
```

### 修改后
```python
def scan_directory(self, directory, audit_start_date, audit_end_date, progress_callback=None):
    self.scan_results = []
    self.total_files = 0
    self.scan_start_time = datetime.now()

    # 统一日期类型：Web 端传入 datetime，GUI 传入 date
    if isinstance(audit_start_date, datetime):
        audit_start_date = audit_start_date.date()
    if isinstance(audit_end_date, datetime):
        audit_end_date = audit_end_date.date()

    if not os.path.exists(directory):
```

## 3. `api.py` — 移除 `/api/open-file` 危险接口

### 修改前
```python
@app.route('/api/open-file', methods=['POST'])
def open_file():
    data = request.get_json()
    file_path = data.get('file_path', '')
    
    if not file_path or not os.path.exists(file_path):
        return jsonify({'error': '文件不存在'}), 400
    
    try:
        os.startfile(file_path)
        return jsonify({'success': True})
    except Exception as e:
        return jsonify({'error': str(e)}), 500

if __name__ == '__main__':
    app.run(debug=True, host='0.0.0.0', port=5000)
```
